# Paletas do usuário

Coloque aqui arquivos `<nome>.hex`: uma cor por linha, sem `#` (formato `.hex` do
Lospec). Linhas vazias e comentários com `;` são ignorados.

```
; minha-paleta.hex
1a1c2c
5d275d
b13e53
```

Uma paleta aqui com o mesmo nome de uma embutida a substitui.
Use com `--palette minha-paleta` ou no `pixelforge.toml`.
